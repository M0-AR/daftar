Feature parity with the reference product

Daftar is an independent rebuild of the feature set advertised for a commercial local-RAG desktop app (reviewed 2026-11-09 from its public website, FAQ and published screenshots). No code, text, name or artwork from that product is used; only the publicly described capabilities were taken as requirements.

Deliberately not copied

  • Pricing tiers, licensing/plan badge, early-access offer: not product features of a local tool.
  • Marketing copy, product name, logo, colours and taglines.

Known limits

  • Scanned PDFs and photos need a vision model in Ollama (PaddleOCR-VL recommended); it needs a recent Ollama and, in practice, a GPU.
  • Arabic/RTL text exports to PDF without glyph shaping (DOCX/HTML/MD/TXT are fine).
  • Match % in keyword-only mode is word coverage; it becomes meaning-aware once a search model is installed.
